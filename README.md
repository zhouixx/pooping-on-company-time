# 带薪摸鱼

一个用于计算工作日、税前时薪和摸鱼收益的 React + Vite 五步互动工具。

## 本地运行

```bash
npm install
npm run dev
```

五个步骤使用同一个开发服务：

| 地址 | 内容 |
| --- | --- |
| `http://localhost:5173/01` | 01 工作节奏 |
| `http://localhost:5173/02` | 02 薪资设置 |
| `http://localhost:5173/03` | 03 本月结果 |
| `http://localhost:5173/04` | 04 月历 |
| `http://localhost:5173/05` | 05 摸鱼计时器 |

各页面顶部可直接跳转上一步、下一步或任意步骤。访问根路径 `/` 时兼容显示 01。

验证命令：

```bash
npm test
npm run build
```

## 规则

- 单休：周日休息，周六上班。
- 双休：周六、周日休息。
- 大小周：选择当前周类型，之后按自然周交替。
- 时薪按税前月薪、实际工作日和每天上班小时数计算。
- 计时器默认按分钟结算，也可以切换为按秒或按小时。
- 05 页显示“今日已赚”：当天已结束会话的累计收益，加上当前会话收益；跨自然日自动归零。
- 非工作日不会启动摸鱼计时器。

## 日历数据

页面优先请求公开年度节假日接口（`timor.tech`）。网络不可用、请求超时、返回格式异常或 HTTP 失败时，会自动使用本地回退数据，并在页面标出数据来源。用户可以点击月历日期保存浏览器本地修正。

## 持久化

用户设置、日期修正和当前计时器状态写入同一站点共享的 `localStorage`。从上一版升级时会自动读取同名 Cookie，迁移到 `localStorage` 后删除旧 Cookie。计时器使用时间戳恢复运行进度，不依赖页面是否一直打开。

## Vercel 部署

项目内的 `vercel.json` 会将 `/01`～`/05` 的直接访问和刷新回退到 React 入口。Vercel 项目使用以下设置：

```text
Build Command: npm run build
Output Directory: dist
```
